# 📚 Библиотека — Управление

Курсовая работа по .NET Framework (WPF + C# + Entity Framework + SQL Server).

## 📌 О проекте

Приложение для управления библиотекой. Позволяет вести учёт книг, авторов, жанров, читателей и выдач.

**Основные возможности:**
- Управление книгами (добавление, редактирование, удаление)
- Управление читателями
- Выдача и возврат книг
- Поиск и фильтрация по всем таблицам
- Отчёты с диаграммами (LiveCharts)
- Контекстное меню (правый клик по таблице)

## 🛠 Технологии

- **C#** (.NET 8.0)
- **WPF** (Windows Presentation Foundation)
- **Entity Framework Core** (Code First)
- **SQL Server / LocalDB**
- **LiveCharts** (диаграммы)

## 📊 Структура базы данных

Приложение использует 5 таблиц:
`Authors` - Авторы книг
`Genres` - Жанры книг
`Books` - Книги
`Readers` - Читатели
`BookLoans` - Выдачи книг

## 🚀 Как запустить

### Требования
- Visual Studio 2022
- .NET 8.0 SDK
- SQL Server Express / LocalDB

### Шаги

1. **Клонируй репозиторий:**
   ```bash
   https://github.com/Albert3424/LibraryManager.git
   ```

2. **Открой решение в Visual Studio:**
   - Файл → Открыть → Проект/Решение → выбери `Library.sln`

3. **Восстанови NuGet-пакеты:**
   - ПКМ по решению → **"Восстановить пакеты NuGet"**

4. **Примени миграции (создай базу данных):**
   - Открой **Консоль диспетчера пакетов** (Вид → Другие окна → Консоль диспетчера пакетов)
   - Выполни:
     ```powershell
     Update-Database
     ```

5. **Запусти приложение:**
   - Нажми `F5` или кнопку **"Пуск"**
